# obarafelomaracountdown

🎬 سينوغرافيا — Event Countdown Landing Page
A modern Arabic RTL landing page created for سينوغرافيا, featuring a live countdown to an upcoming event with event details and reservation/contact actions.

✨ Features
🌙 Dark, cinematic visual design
🇸🇦 Full Arabic / RTL interface
⏳ Live countdown timer
📅 Displays event date and time
📍 Event location information
🎟️ Reservation / ticket button
🌐 Website button
📱 Responsive layout
❤️ Minimal and elegant UI
📸 Preview
Sinegrafia Event Countdown

🗓️ Event Information
The landing page displays:

Event: رحلة جديدة مع فريق سينوغرافيا
Date: الأحد
Time: الساعة السابعة مساءً
Location: مسرح كلية سان مارك
The countdown automatically shows the remaining days, hours, minutes, and seconds until the event.

🎨 Design
The design focuses on a simple cinematic experience:

Black background
Gold/yellow accent color
White typography
Rounded countdown cards
Subtle glowing effects
RTL Arabic layout
